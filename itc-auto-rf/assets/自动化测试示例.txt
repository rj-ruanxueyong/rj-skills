## TEST-CASE 2
### 用例描述
用例编号：IT-UC-NH-WEIGHT-023
用例名称：第三级WCMP出口link变化
测试类型：可靠性测试
用例等级：L0
适用产品：s6950
来源项目：12.5SPR37
测试描述：
1.配置四个三层口并配置静态邻接
2.开启WCMP开关并配置SRv6路由
3.从其中一个路由口打入IPv6报文命中路由
4.查看端口计数
5.分别shutdown/no shutdown（间隔5s）WCMP的单个成员口各一次，全部成员恢复up后并查看端口计数
6.shutdown带权重的最后一个成员口并查看端口计数
7.全部成员恢复up后查看端口计数
8.查看syslog是否报错
备注：

### 用例步骤
1. DUT配置四个三层口并配置静态邻接
```DUT
configure
int <port1>
no sw
ipv6 address 2009::1/64
!
int <port2>
no sw
ipv6 address 200a::1/64
!
int <port3>
no sw
ipv6 address 200b::1/64
!
int <port4>
no sw
ipv6 address 200c::1/64
!
ipv6 neighbor 2009::2 <port1> 0000.0000.0009
ipv6 neighbor 200a::2 <port2> 0000.0000.000a
ipv6 neighbor 200b::2 <port3> 0000.0000.000b
ipv6 neighbor 200c::2 <port4> 0000.0000.000c
```
配置完成后有预期结果1
2. 开启WCMP开关并配置SRv6路由
```DUT
configure
weight enhance enable
！
segment-routing ipv6
locator ggaa default
prefix 8000:8000:: 48 bind-sid 16
opcode ::6:2 end-x interface <port2> nexthop 200a::2 psp
opcode ::6:2 end-x interface <port3> nexthop 200b::2 psp
opcode ::6:2 end-x interface <port4> nexthop 200c::2 weight 3 psp
opcode ::6:2 end-x commit
!
!
segment-routing traffic-eng
segment-list srv6-1 srv6
index 1 srv6 8000:8000::6:2
index 2 srv6 1000:1000::1
commit
!
policy srv6-1 color 1 end-point 1111::1 srv6
bind-sid srv6 8000:8000::1
candidate-path 1 explicit
segment-list srv6-1
exit-sidlist-mode
exit-candpath-mode
!
!
!
ipv6 route 2123::/16 srp srv6 srv6-1
```
配置完成后有预期结果2
3. 从其中一个路由口打入IPv6报文命中路由
<port1> 配置IPV6报文：SMAC:0000.0001.0001, DMAC:三层MAC，SIPv6:1000::2, DIPv6:2123::1，变化50000，速率100000pps
等待5s后查看端口计数，有预期结果3和4
4. 分别shutdown/no shutdown（间隔5s）WCMP的单个成员口各一次，全部成员恢复up后并查看端口计数
等待5s后抓包统计，有预期结果5
5. shutdown带权重的最后一个成员口并查看端口计数
等待5s后抓包统计，有预期结果6
6. 全部成员恢复up后查看端口计数
等待5s后抓包统计，有预期结果7
7. 查看syslog是否报错
有预期结果8

### 用例预期结果
1. 通过show ipv6 neighbor查看配置成功；
2. 通过show segment-routing policy srv6和show ipv6 route查看配置成功；
3. 流量构造及打流成功；
4. 端口9输入速率100000pps，端口10-12输出速率分别是20000pps、20000pps、60000pps；
5. 端口9输入速率100000pps，端口10-12输出速率分别是20000pps、20000pps、60000pps；
6. 端口9输入速率100000pps，端口10-11输出速率分别是50000pps、50000pps；
7. 端口9输入速率100000pps，端口10-12输出速率分别是20000pps、20000pps、60000pps；
8. 通过show logging | include error查看无syslog报错;
